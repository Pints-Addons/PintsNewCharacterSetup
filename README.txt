Pint's New Character Setup v1.0 - every new character starts with default settings that make sense
(WoW Classic Era / Hardcore / Forever)

REQUIRES
  Nothing. Works on its own.

INSTALL
  Unzip so the folder sits at:  World of Warcraft\_classic_era_\Interface\AddOns\PintsNewCharacterSetup
  Restart the game.

WHY
  The game saves settings like Auto Loot per character, so every new character starts with them off and you
  set them up again. This add-on does it for you the first time each character logs in.

HOW TO USE
  /setup (or /pns, /newchar), or Esc > Options > AddOns > Pint's New Character Setup.

  EVERY NEW CHARACTER STARTS WITH - tick what you want:
    [x] Auto Loot
    [x] Cooldown numbers on action bars
    [x] Class-coloured names in chat (every chat type and channel)
    [x] Target of Target
    [x] Maximum camera distance
    [x] Track quests when accepted
    [ ] Open loot window at mouse
  Each character gets these on its first login with the add-on (it says in chat what it turned on).
  After that you can change them on that character as normal - the add-on won't switch them back.
  "Apply to this character now" (or /setup apply) turns them on for the character you're playing.

  COOLDOWN NUMBERS (all characters)
  Large, outlined countdown numbers on your action bars - Blizzard bars, Dominos, Bartender and Pint's Bars.
  Choose the size (default 26; the game's is about 16) and the colour (yellow, white, orange, green, light blue).

  ITEM TOOLTIPS (all characters)
  "Stacks to: 20" on anything that stacks, and "Used in: Tailoring, First Aid" on crafting materials.
  Each line can be switched off.

NOTES
  Your existing characters get the ticked defaults on their first login with the add-on too.
  Untick anything you don't want before logging them in.
